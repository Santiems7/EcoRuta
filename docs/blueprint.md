# **App Name**: EcoRuta Calasanz

## Core Features:

- Visual Residue Classifier: Uses the device's camera to identify a waste item and determine if it is organic, recyclable, or non-recyclable using image analysis.
- Interactive Unit Map: Displays an interactive map of the Unidad Residencial Mirador de Calasanz, showing the locations of all waste disposal points (organic, recycling, and general waste).
- Waste Sorting Guides: Provides quick video guides demonstrating proper waste sorting techniques, including what is compostable and recyclable.
- Community Impact Statistics: Displays weekly statistics on the amount of organic waste diverted from landfills and recyclable materials collected by the community.
- Gamified Participation: Encourages user participation through gamification, awarding points for correct waste disposal and offering internal raffles.
- Intelligent Waste Sorting Tool: LLM-powered waste sorting tool where users can take pictures of waste items. Based on the item, and information about waste acceptance policies in the user's location, the tool returns text or video directions for how the user should sort the waste.

## Style Guidelines:

- Primary color: Forest green (#388E3C) to represent nature and sustainability.
- Background color: Light beige (#F5F5DC) to provide a clean and calming backdrop.
- Accent color: Earthy brown (#795548) for highlighting key elements and CTAs.
- Body and headline font: 'PT Sans' for a clean and readable interface.
- Use clear, intuitive icons representing different waste categories (organic, plastic, glass, paper).
- Clean and straightforward layout with a focus on ease of navigation. Prioritize larger touch targets for user interaction.
- Subtle animations to provide feedback and guide users through the waste sorting process. Examples: A smooth transition when scanning a residue, or a confirmation animation when submitting data.
